# Налаштування з iPhone — крок за кроком (без комп'ютера)

Це інструкція простими словами. Все робиться в **Safari** на iPhone.
Назви кнопок у Railway, Google і Claude інколи змінюються — шукайте схожі слова.

## Що ми робимо

Є три частини, як три ключі від одних дверей:

1. **Сервер на Railway** — маленька програма, яка живе в інтернеті і вміє керувати YouTube.
2. **Ключ від Google** — дозвіл, щоб сервер міг працювати з вашим YouTube-каналом.
3. **Підключення в Claude** — ви додаєте адресу сервера в Claude, і він отримує нові «кнопки» для YouTube.

Ваш YouTube може бути на іншому Google-акаунті — це нормально. Нижче цей акаунт називається **«акаунт YouTube»**.

## Що потрібно мати

- Акаунт **GitHub** з цим репозиторієм (він у вас є).
- Акаунт **Railway** (входити через GitHub). Railway може бути платним — зазвичай кілька доларів на місяць; актуальну ціну дивіться на railway.com/pricing.
- **Акаунт YouTube** (Google-акаунт, на якому канал) і його пошта.
- **Claude** з можливістю додавати власні конектори (custom connectors). Якщо такого пункту немає в налаштуваннях, перевірте свій тариф.

> 💡 **Порада для Google Cloud.** Сайт Google Cloud незручний на телефоні. У Safari натисніть **«aA»** у рядку адреси → **«Запит настільного вебсайту»** (Request Desktop Website). Телефон краще тримати горизонтально.

## Крок 1. Прийміть Pull Request у GitHub

1. Відкрийте GitHub (застосунок або github.com) → ваш репозиторій `maagpi-youtube-mcp` → вкладка **Pull requests**.
2. Відкрийте мій Pull Request → прокрутіть вниз → **Merge pull request** → **Confirm merge**.

Тепер усе потрібне є в гілці `main`.

## Крок 2. Запустіть сервер на Railway

1. Відкрийте **railway.com** → **Login** → **Login with GitHub**.
2. **New Project** → **Deploy from GitHub repo** → виберіть `maagpi-youtube-mcp`.
   (Якщо Railway просить доступ до GitHub — дозвольте доступ до цього репозиторію.)
3. Railway сам збере сервер (він знайде файл `Dockerfile`). Зачекайте кілька хвилин, поки біля сервісу з'явиться «Active».
   Спочатку сервер скаже, що йому ще не вистачає налаштувань. **Це нормально** — далі ми їх додамо.

## Крок 3. Отримайте адресу сервера

1. Натисніть на свій сервіс → **Settings** → розділ **Networking** → **Generate Domain**.
   Якщо Railway запитає порт — впишіть `3000`.
2. З'явиться адреса на кшталт `https://назва.up.railway.app`. Запишіть її — це **ВАША-АДРЕСА**.
3. У Safari відкрийте **ВАША-АДРЕСА** (без нічого після неї). Ви побачите сторінку з трьома блоками:
   - **список того, чого не вистачає**;
   - **Redirect URI** — довге посилання, воно закінчується на `/oauth/google/callback`;
   - **згенерований ключ** для `TOKEN_ENCRYPTION_KEY`.

   Натисніть і потримайте текст, щоб скопіювати. Збережіть їх в **Нотатки** — вони знадобляться.

## Крок 4. Ключ від Google

Тут можна входити **будь-яким** Google-акаунтом (не обов'язково акаунтом YouTube).

1. Відкрийте **console.cloud.google.com** (у настільній версії сайту).
2. Угорі: вибір проєкту → **New project** → назва, наприклад `youtube-claude` → **Create**. Переконайтесь, що він вибраний.
3. Меню ☰ → **APIs & Services** → **Library**. Знайдіть і натисніть **Enable** для двох API:
   - **YouTube Data API v3**
   - **YouTube Analytics API**
4. Меню ☰ → **APIs & Services** → **OAuth consent screen** (або «Google Auth Platform»):
   - Тип користувачів: **External**.
   - Назва застосунку: що завгодно (наприклад `Мій YouTube`), пошта підтримки і пошта розробника — ваші.
   - **Дуже важливо:** знайдіть **Publishing status** (розділ **Audience**) і натисніть **Publish app** → підтвердіть, щоб статус став **In production**.
     Якщо залишити **Testing**, Google «забуде» вхід через 7 днів, і доведеться підключатися знову.
     Перевіряти застосунок у Google **не потрібно** — ви лише один раз натиснете «Все одно продовжити».
   - (Бажано) у розділі **Data Access** / **Scopes** додайте дозволи: `youtube`, `youtube.force-ssl`, `youtube.upload`, `yt-analytics.readonly`, `yt-analytics-monetary.readonly`.
5. Меню ☰ → **APIs & Services** → **Credentials** → **Create credentials** → **OAuth client ID**:
   - Application type: **Web application**.
   - У **Authorized redirect URIs** → **Add URI** → вставте **Redirect URI** зі сторінки сервера (крок 3).
   - **Create**.
6. З'явиться вікно з **Client ID** та **Client secret**. Скопіюйте обидва в Нотатки.
   (**Client secret** — це пароль. Нікому його не надсилайте і не вставляйте в GitHub.)

## Крок 5. Вставте налаштування в Railway

1. Railway → ваш сервіс → вкладка **Variables**.
2. Додайте змінні (кнопка **New Variable**, або **Raw Editor** — тоді вставте все одним блоком):

   | Назва | Що вписати |
   |---|---|
   | `YOUTUBE_CLIENT_ID` | Client ID з кроку 4 |
   | `YOUTUBE_CLIENT_SECRET` | Client secret з кроку 4 |
   | `TOKEN_ENCRYPTION_KEY` | ключ зі сторінки сервера (крок 3) |
   | `ALLOWED_GOOGLE_EMAILS` | пошта **акаунта YouTube**, наприклад `ivan@gmail.com` |
   | `PORT` | `3000` |

3. Railway сам перезапустить сервер. Через хвилину оновіть сторінку **ВАША-АДРЕСА** — має бути зелений напис
   **«Сервер працює і налаштований ✅»**.

   Хочете, щоб підключитись міг лише один конкретний канал? Додайте ще `YOUTUBE_CHANNEL_ID` з ID каналу (необов'язково).

## Крок 6. Підключіть Claude

1. Відкрийте **claude.ai** у Safari (або застосунок Claude) → ваш профіль → **Settings** → **Connectors**.
2. **Add custom connector** (Додати власний конектор):
   - Name: `YouTube`
   - URL: **ВАША-АДРЕСА/mcp** — тобто з `/mcp` наприкінці, наприклад `https://назва.up.railway.app/mcp`
   - Поля «Advanced settings» (Client ID / Secret) **залиште порожніми**.
3. Натисніть **Add**, потім **Connect**.
4. Відкриється вхід Google:
   - Виберіть **акаунт YouTube** (той, що в `ALLOWED_GOOGLE_EMAILS`). Якщо Google питає, який канал — виберіть потрібний.
   - Побачите попередження «Google hasn't verified this app» — це нормально, застосунок ваш. Натисніть **Advanced** → **Go to … (unsafe)**.
   - **Залиште всі галочки ввімкненими** → **Continue / Allow**.
5. Вас поверне в Claude, конектор стане «Connected».
6. У новому чаті натисніть **+** → **Connectors** → увімкніть **YouTube**.

Перевірка: напишіть Claude **«Покажи, який YouTube-канал підключено»**. Він назве пошту й канал. Якщо канал не той — відключіть конектор і підключіть знову, вибравши інший канал.

> 💡 У налаштуваннях конектора Claude дозволяє для кожної дії вибрати «Завжди дозволяти» або «Питати перед виконанням». Читання (статистика, списки) можна дозволити завжди, а зміни — залишити «Питати».

## Як користуватися

### Завантажити відео або Shorts
1. Покладіть відео (MP4/MOV) на **Google Drive** або **Dropbox**.
2. Поділіться файлом: **«Усі, хто має посилання»** (Anyone with the link) → скопіюйте посилання.
   *iCloud-посилання не працюють* — завантажте файл на Google Drive або Dropbox.
3. Напишіть Claude: «Завантаж це відео як Shorts, назва …, опис …, теги …: *посилання*».
4. Claude запустить завантаження у фоні і скаже, коли воно закінчиться. Відео завжди завантажується **приватним**.
5. Після завантаження можна закрити доступ до файлу на Drive/Dropbox.

### Опублікувати або запланувати — тільки з вашим підтвердженням
1. Скажіть: «Опублікуй це відео» або «Заплануй на 20 січня о 18:00».
2. Claude **нічого не публікує**, а дає вам **посилання на підтвердження**.
3. Натисніть на посилання → побачите назву відео, дію і час → натисніть **«Підтвердити»**.
4. Поверніться в Claude і напишіть «підтвердив». Тоді Claude виконає дію.

Посилання одноразове і діє 30 хвилин. Claude не може натиснути цю кнопку замість вас.

### Інше
- Змінити назву, опис, теги, обкладинку відео; плейлисти; опис і ключові слова каналу; банер.
- Подивитися статистику: «топ-5 відео за місяць», «перегляди за останні 28 днів».
- Коментарі: «покажи свіжі коментарі на каналі» → Claude пропонує відповіді → **публікує лише після вашого «ок»**.

## Чого немає (і чому)

**Відео видалити не можна** — такого інструменту в сервері просто немає.

**Офіційний YouTube API цього не вміє, тому сервер теж не може:**
- змінити **назву каналу, @нікнейм і аватарку** (робіть у застосунку YouTube або YouTube Studio);
- створити **Прем'єру**;
- **закріпити** коментар або поставити йому серце;
- змінити **обкладинку плейлиста**, **заставки та підказки** (end screens / cards);
- «позначити» відео як Shorts: Shorts — це просто вертикальне (або квадратне) відео до 3 хвилин.

**Важливе обмеження від Google:** відео, завантажені через API-проєкт, який не пройшов аудит Google, можуть **залишатися приватними** — навіть після вашого підтвердження. Тоді сервер покаже попередження. Що робити: подати безкоштовну заявку на аудит («YouTube API Services — Audit and Quota Extension Form») або опублікувати такі відео вручну в YouTube Studio.

**Ліміти:** безкоштовний щоденний ліміт YouTube — 10 000 «очок»; одне завантаження коштує 1 600, тобто близько шести завантажень на день. Обкладинки власного дизайну потребують підтвердженого каналу (підтвердження телефоном).

## Якщо щось пішло не так

| Що бачите | Що робити |
|---|---|
| Сторінка сервера пише, що чогось не вистачає | Додайте відсутню змінну в Railway → Variables |
| Google: `redirect_uri_mismatch` | У Google Cloud → Credentials → ваш клієнт → Redirect URI має **точно** збігатись з тим, що на сторінці сервера |
| Google: «Access blocked» / «app is in testing» | Крок 4: натисніть **Publish app** (In production), або додайте акаунт YouTube у **Test users** |
| «Цей Google-акаунт не має доступу» | Ви увійшли не тим акаунтом, або його пошти немає в `ALLOWED_GOOGLE_EMAILS` |
| Claude просить підключитися знову приблизно через 7 днів | Застосунок Google залишився в режимі Testing → крок 4, **Publish app** |
| Claude пише «redirect_uri is not allowed: …» | Скопіюйте адресу з повідомлення в змінну `ALLOWED_REDIRECT_URIS` у Railway |
| «The link opens a web page, not a file» | Посилання не прямі: поділіться файлом як «Усі, хто має посилання» |
| Відео лишилось приватним після підтвердження | Обмеження Google — див. вище про аудит |

## Як усе вимкнути

- **Закрити доступ сервера до YouTube:** myaccount.google.com/permissions (під акаунтом YouTube) → ваш застосунок → **Видалити доступ**.
- **Розлогінити всіх:** у Railway змініть `TOKEN_ENCRYPTION_KEY` на будь-яке інше довге значення — після цього Claude попросить підключитися знову.
- **Зупинити сервер:** у Railway зупиніть або видаліть сервіс.
